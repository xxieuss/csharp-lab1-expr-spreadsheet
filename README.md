# Електронна таблиця з обчисленням виразів

Лабораторна робота №1. Варіант 33.

Клітинки таблиці містять вирази з цілих чисел довільної довжини, посилань на інші клітинки (`A1`, `B12`) та операцій варіанта 33. Обробка виразу у два етапи: синтаксична перевірка з локалізацією помилки, потім обчислення значення.

Відображення таблиці підтримує два режими: **ВИРАЗ** і **ЗНАЧЕННЯ**.

## Операції

| Операції | Пріоритет |
| --- | --- |
| `not` | найнижчий |
| `<=` `>=` `<>` | порівняння |
| `+` `-` (бінарні) | |
| `*` `/` | |
| `^` (піднесення до степеня) | правоасоціативний |
| `+` `-` (унарні) | найвищий |

Значення клітинки може бути або цілим числом довільної довжини, або логічним значенням.

## БНФ

```
<оператор>   ::= <клітинка> ":=" <вираз> | "if" <вираз> "then" <оператор> | <вираз>
<вираз>      ::= <логічний>
<логічний>   ::= "not" <логічний> | <порівняння>
<порівняння> ::= <сума> [ ("<=" | ">=" | "<>") <сума> ]
<сума>       ::= <добуток> { ("+" | "-") <добуток> }
<добуток>    ::= <степінь> { ("*" | "/") <степінь> }
<степінь>    ::= <унарний> [ "^" <степінь> ]
<унарний>    ::= ("+" | "-") <унарний> | <первинний>
<первинний>  ::= <число> | <клітинка> | "(" <логічний> ")"
<число>      ::= <цифра> { <цифра> }
<клітинка>   ::= <літера> { <літера> } <цифра> { <цифра> }
```

Порядок правил задає пріоритети – від найслабшого до найсильнішого. `^` рекурсує сам у себе справа, тому `2^3^2` = `2^(3^2)` = 512. Порівняння не повторюється: `A1 <= B1 <= C1` є синтаксичною помилкою.

Правило `<оператор>` – це спрощена мова програмування: у клітинці можна записати не лише вираз, а й оператор присвоєння та умовний оператор.

## Структура

- `ExprSheet/Core` – розбір, обчислення, модель таблиці, збереження
- `ExprSheet/ConsoleTest` – консольний стенд для перевірки `Core` без інтерфейсу
- `docs` – UML-діаграми: use-case, діаграма класів, діаграма послідовності
