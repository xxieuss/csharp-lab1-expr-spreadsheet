# Електронна таблиця з обчисленням виразів

Лабораторна робота № 1. Варіант 33.

Клітинки таблиці містять вирази з цілих чисел довільної довжини, посилань на інші клітинки (`A1`, `B12`) та операцій варіанта 33. Обробка виразу у два етапи: синтаксична перевірка з локалізацією помилки, потім обчислення значення.

Відображення таблиці підтримує два режими: **ВИРАЗ** і **ЗНАЧЕННЯ**.

## Операції

| Операції | Пріоритет |
| --- | --- |
| `not` | найнижчий |
| `<=` `>=` `<>` | порівняння |
| `+` `-` (бінарні) | |
| `*` `/` | |
| `^` (піднесення до степеня) | правоасоціативний |
| `+` `-` (унарні) | найвищий |

Варіант 33 належить до діапазону 20–81, тому вираз вважається логічним: значення клітинки може бути або цілим числом довільної довжини, або логічним значенням.

## БНФ

```
<оператор>   ::= <клітинка> ":=" <вираз> | <умовний> | <вираз>
<умовний>    ::= "if" <вираз> "then" ( <умовний> | <вираз> )
<вираз>      ::= <логічний>
<логічний>   ::= "not" <логічний> | <порівняння>
<порівняння> ::= <сума> [ ("<=" | ">=" | "<>") <сума> ]
<сума>       ::= <добуток> { ("+" | "-") <добуток> }
<добуток>    ::= <степінь> { ("*" | "/") <степінь> }
<степінь>    ::= <унарний> [ "^" <степінь> ]
<унарний>    ::= ("+" | "-") <унарний> | <первинний>
<первинний>  ::= <число> | <клітинка> | "(" <логічний> ")"
<число>      ::= <цифра> { <цифра> }
<клітинка>   ::= <літера> { <літера> } <цифра> { <цифра> }
```

Порядок правил задає пріоритети — від найслабшого до найсильнішого. `^` рекурсує сам у себе справа, тому `2^3^2` = `2^(3^2)` = 512. Порівняння не повторюється: `A1 <= B1 <= C1` є синтаксичною помилкою.

Правила `<оператор>` і `<умовний>` — це спрощена мова програмування (додаткові два бали): у клітинці можна записати не лише вираз, а й оператор присвоєння та умовний оператор. Присвоєння допускається лише на початку вмісту клітинки, бо адресат запису має бути відомий до обчислення — граф залежностей будується наперед.

## Структура

- `ExprSheet/Core` — логіка: розбір, обчислення, модель таблиці, збереження
- `ExprSheet/ConsoleTest` — консольний стенд для перевірки `Core` без інтерфейсу
- `ExprSheet/Ui` — інтерфейс на .NET MAUI
- `docs` — UML-діаграми: use-case, діаграма класів, діаграма послідовності

`Core` не залежить від MAUI, тому вся логіка перевіряється без запуску вікна.

## Запуск

Консольний стенд:

```bash
cd ExprSheet
dotnet run --project ConsoleTest
```

Графічний інтерфейс (macOS):

```bash
cd ExprSheet
dotnet build Ui/Ui.csproj -f net10.0-maccatalyst
dotnet build Ui/Ui.csproj -f net10.0-maccatalyst -t:Run
```

## Google Drive

Таблиці можна зберігати не лише локально, а й на Google Drive. Для цього потрібен власний обліковий запис OAuth, бо `client_secret.json` не зберігається в репозиторії:

1. створити проєкт у [Google Cloud Console](https://console.cloud.google.com/);
2. увімкнути **Google Drive API**;
3. на екрані згоди додати свою пошту до списку **Test users**;
4. створити облікові дані типу **Desktop app**;
5. завантажений файл перейменувати на `client_secret.json` і покласти
   в `ExprSheet/Ui/Resources/Raw/`.

Застосунок запитує право `drive.file` — доступ лише до файлів, які створив сам.
